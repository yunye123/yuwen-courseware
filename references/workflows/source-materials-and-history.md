# 本课资料与个人教学资产

## 一、开始备课前

公开核心版不随 Skill 安装教材、课程标准、教参或教师课例。开始前，宿主应以自然中文确认本课的资料：

> 请提供本课使用的教材版本、篇目或原文，以及可用于核对的课标、注释或教参材料。没有可靠原文的部分，我会标为待核，不会凭记忆补写。

资料可以是老师直接上传的文件、老师明确许可的摘录、官方公开链接，或其他可合法使用的材料。每种资料至少记录：名称、版本或版次、提供者/发布者、来源、可用范围和本课用途。材料不完整、版本冲突或权利不明时，先提出缺口，不得静默混用。

## 二、事实与引文核对

`<PYTHON>` 由宿主先解析为已验证的 Python 3.10+ 执行器：macOS/Linux 通常为 `python3`，Windows 通常为 `py -3`。将本课实际引用的原文保存到使用者私有课例目录后，可使用：

```text
<PYTHON> scripts/quote_check.py --checklist <课例内/逐字校对清单.json>
```

清单中的 `sources` 只能指向课例目录内的普通 UTF-8 文本文件，`quotes` 逐条登记实际使用的引文。工具只比较已有文本，不下载、不生成、也不推断教材内容。引文、作者、版本或事实无法核对时，应在教师成品中避免断言或明确标记为待教师确认。

## 三、个人课例与经验

所有课例保存在 `YUWEN_DATA_HOME/lessons/`，不得写回 Skill 安装目录。完成或恢复课例后，可运行：

```text
<PYTHON> scripts/teaching_library.py rebuild-index --data-home <个人教学资料目录>
```

索引只属于当前使用者的数据目录。授课后，把 `assets/templates/10-post-class-reflection.md` 放入课例目录并根据真实反馈填写；只有老师明确选择“加入我的教学经验库”后，才填写 `11-personal-experience-card.md` 并运行 `promote`。不得根据模型自评自动晋级，也不得把未脱敏学生信息、他人课例或未经同意的材料写入经验库。

## 四、公开仓边界

公开仓只保存通用流程、模板、代码和测试。不得把老师提供的教材、课标、课文、截图、音视频、学生信息、课堂作品或个人课例提交到这个仓库；贡献示例应使用自创或明确可再分发的材料。
