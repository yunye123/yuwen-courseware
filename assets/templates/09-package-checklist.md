## 一、老师最终收到的文件

- [ ] 已批准教学设计
- [ ] 课堂主线与问题链
- [ ] 日常教学设计
- [ ] 授课导航稿
- [ ] 白底可编辑课件
- [ ] 四份默认成品均使用中文文件名
- [ ] 课件完整呈现课堂核心问题、活动步骤、学生指令与反馈节点
- [ ] 教师成品中没有内部编号、检查记录、制作说明或软件提示
- [ ] 教学设计主体已经写清教师组织、学生行动、回答分支、追问反馈、时间和转场，不需要老师现场补猜
- [ ] 导入能在三分钟内回到文本，整课情境贯穿核心问题、活动和学生成果
- [ ] 板书提供可视化空间结构和课堂生成顺序，不是关键词清单
- [ ] 授课导航稿第一页有课堂导航，老师低头一眼能找到下一步，超时五分钟时能立即找到删减方案
- [ ] 教师交付文件夹没有研究记录、来源台账、结构数据和中间稿

## 二、学案判断

- [ ] 已根据课堂设计判断是否需要纸质学案，并取得老师意见
- [ ] 不需要学案：未生成、未打包学生学案与独立参考答案
- [ ] 需要学案：学生学案与教师参考答案成对生成、成对交付
- [ ] 无学案时，所有学生任务已完整进入课件，必要答案与反馈已进入授课导航稿或课件备注

## 三、内部检查（不进入教师交付文件夹）

- [ ] 教学设计、授课导航稿、课件及可选学案已逐项核对一致
- [ ] 课文引文与关键事实已核对
- [ ] 学生可见页面没有提前泄露答案
- [ ] 素材来源和可使用范围已核对
- [ ] 未发现密钥、登录信息、开发机路径或未脱敏学生信息
- [ ] 内部归档保留研究记录、检查报告、版本记录与结构数据

## 四、实际授课设备验收

以下项目是公开核心版的人工交付检查，不得用自动导出或预览代替：

- [ ] Markdown 教学设计与授课导航稿可在老师常用工具中打开、编辑和打印
- [ ] 白底课件可在目标设备中打开、编辑和放映
- [ ] 若老师自行转换 DOCX/PDF，目标软件中的分页和打印已另行检查
- [ ] 尚未覆盖的设备或软件版本已明确写为待验证，不误称已验证
