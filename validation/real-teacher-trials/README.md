# 常态课真实教师验证模板

> 本目录仅提供空白模板和通用判定口径；没有任何真实教师、课堂或学生数据。

这套模板用于验证高中语文常态课：教师能否较快看清课堂主线、形成可修改底稿，并把核心活动实际带入课堂。它不验证公开课、高三专题、作文、整本书阅读或任何新功能。

## 使用顺序

1. 向参加教师发送[试用说明](real-teacher-trial-guide.md)，为每位教师分配匿名编号。
2. 每次真实试用依次填写 `templates/01` 至 `05`；完成后填写 `templates/06`。
3. 六位教师都完成有效试用后，用 `templates/07` 汇总，逐项对照冻结标准。
4. 后续修改建议必须附试次编号和证据编号；没有真实证据的想法只能保留为待验证。

真实填写后的表单、课堂材料和证据不得提交到本仓库；`data/` 已被 Git 忽略。不得提交教师姓名、学校、班级、学生信息、教材全文、录音录像、截图、账户资料或本机路径。

## 有效试次

一份有效试次须有匿名背景、备课过程、内容修改、至少一项核心活动的课堂记录、访谈和单次汇总。缺少任一项时不计入通过率，只能标为数据不完整。

## 冻结标准

| 编号 | 通过线 |
|---|---|
| A1 | 至少完成 6 位真实教师的有效试次 |
| A2 | 至少 5 位教师在 10 分钟内看到有价值的课堂主线 |
| A3 | 至少 4 位教师在 30 分钟内得到可继续修改的完整底稿 |
| A4 | 至少 5 位教师能在 30 秒内说清核心问题和课堂路线 |
| A5 | 至少 70% 的核心活动无需推翻重写 |
| A6 | 至少 70% 的核心活动实际用时与设计用时误差不超过 3 分钟 |
| A7 | 至少 5 位教师认为新流程比原有备课流程更轻 |
| A8 | 不出现未经标记的关键引文或文学常识错误 |
| A9 | 没有教师因默认未提供完整逐字稿而无法完成备课 |
| A10 | 至少 4 位教师明确愿意在下一周继续使用 |

- **通过**：A1—A10 全部达到。
- **部分通过**：至少有 6 个有效试次，课堂主线、路线表达和事实边界稳定，但底稿、活动执行、授课导航或 PPT 存在集中问题；只修改对应模板或规则，不增加新功能。
- **未通过**：样本不足、课堂主线无效、存在未经标记的关键事实/引文错误，或多数教师无法获得可用底稿、推翻核心活动、学生无法理解活动、或不愿继续使用。

六人首轮可直接使用 `templates/07-validation-report.md` 人工汇总；没有必要预先增加数据库或统计平台。
