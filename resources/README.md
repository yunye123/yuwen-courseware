# 安装学习资源层

本目录只收录可随公开学习参考版分发的资源。当前仅包含一篇自创安装示例，用于体验资料登记、引文校对和备课工作流；它不是教材、课标、教参或可直接用于真实课堂的权威材料。

每项资源必须在 `manifest.json` 中记录：权利人、来源类别、许可证、允许用途和文件路径。只有下列任一条件成立的资源才可加入：

1. 项目权利人原创，且明确同意按本仓库的个人学习与参考许可分发；
2. 已进入公版，且所用版本、注释、图片和编排也可再分发；
3. 有明确、可核验且与本仓库许可兼容的再分发授权。

教材、课程标准、教参、课堂录像、教师案例、学生作品和权利不明内容不能加入。对这类材料，仅可在本地私有课例目录中由有权使用者自行提供，并在课例中记录来源与使用范围。
